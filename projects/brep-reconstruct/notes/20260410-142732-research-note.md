## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first method to encode B-rep geometry and topology into a holistic token sequence, enabling autoregressive generation with a transformer.
- **Why It Matters:** Directly generates B-Reps via next-token prediction on a unified sequence representation, outputting the complete data structure without operation sequences.
- **Evidence:** Abstract explicitly states encoding of faces, edges, and topology into tokens for sequence-based generation.

### 2. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Presents a Transformer model that autoregressively generates B-Reps end-to-end from a unified tokenization of geometry and topology.
- **Why It Matters:** Directly generates B-Reps with precise geometry and watertight topology via next-token prediction, avoiding sequential modeling steps.
- **Evidence:** Abstract states the goal is 'directly generating B-Reps end-to-end' and uses a breadth-first traversal of the face adjacency graph.

### 3. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Introduces a neural implicit representation (BR-DF) for B-Rep faces and edges, using a latent diffusion model for generation.
- **Why It Matters:** Outputs a faceted B-Rep model directly from generated signed and unsigned distance functions, representing a continuous neural approach.
- **Evidence:** Abstract describes encoding surface mesh geometry as SDF and per-face UDFs, converted directly to a watertight B-Rep.

### 4. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Proposes a single-stage autoregressive framework using a Voronoi Half-Patch representation and a decoder-only Transformer.
- **Why It Matters:** Directly generates B-Reps in a single stage and demonstrates conditional generation from point clouds, among other inputs.
- **Evidence:** Abstract highlights conditional generation from point clouds and a unified format for geometry and topology.

### 5. DTGBrepGen: A Novel B-rep Generative Model through Decoupling Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2503.13110v1
- **Contribution:** Introduces a topology-geometry decoupled framework using Transformer-based diffusion models for sequential geometry generation.
- **Why It Matters:** Generates valid B-Rep models by first modeling topology, then generating B-spline face geometries, outputting the final structure.
- **Evidence:** Abstract explicitly addresses generating 'valid and high-quality B-rep models' and outputs B-spline faces.

### 6. GraphBrep: Learning B-Rep in Graph Structure for Efficient CAD Generation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2507.04765v1
- **Contribution:** Proposes a graph diffusion model to learn compact topology explicitly, conditioned on surface features, for B-Rep generation.
- **Why It Matters:** Focuses on direct B-Rep generation by modeling the joint distribution of geometry and topology in a graph structure.
- **Evidence:** Abstract states the goal is 'Direct B-Rep generation' and explicitly represents topology in an undirected weighted graph.

### 7. HoLa: B-Rep Generation using a Holistic Latent Representation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2504.14257v3
- **Contribution:** Introduces a holistic latent space that unifies geometry and topology, enabling diffusion-based generation from various inputs including point clouds.
- **Why It Matters:** Encodes a full B-Rep model in a latent space defined only on surfaces, accepting point cloud input for generation.
- **Evidence:** Abstract describes a diffusion-based generator that takes point clouds as input and encodes topology via geometric reconstruction.

## Key Observations

- Dominant architectures are autoregressive transformers (BrepARG, AutoBrep, BrepGPT) and diffusion models (BR-DF, DTGBrepGen).
- A major trend is unified or holistic representations that encode both geometry and topology together (HoLa, BrepARG, AutoBrep) to simplify generation.
- There is a clear shift from multi-stage, cascaded pipelines to single-stage, end-to-end frameworks (e.g., BrepGPT).
- Several methods explicitly accept point clouds as a conditional input modality (BrepGPT, HoLa).
- Ensuring topological validity (watertightness) and handling complex, high-genus solids remain explicit challenges.
