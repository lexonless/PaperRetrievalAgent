## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first autoregressive transformer model to encode B-Rep geometry and topology into a holistic token sequence, enabling sequence-based generation via next-token prediction.
- **Why It Matters:** Directly generates final B-Rep structure end-to-end using a modern transformer architecture. Output is a token sequence representing the complete B-Rep, not a modeling history.
- **Evidence:** Abstract explicitly states encoding into geometry, position, and face index tokens, constructing a holistic sequence, and using a decoder-only transformer for generation.

### 2. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Introduces a hierarchical diffusion framework that decouples geometry modeling, first establishing a topological scaffold, then using Transformer-based diffusion modules to refine face surfaces and vertex positions.
- **Why It Matters:** Directly generates valid B-Rep models using a modern diffusion architecture. Enforces topological constraints during generation to produce structurally consistent outputs.
- **Evidence:** Abstract describes a two-stage process generating face-edge incidence relations (topology) followed by geometry refinement via diffusion, resulting in a complete B-Rep.

### 3. Point2Brep: Geometry-Aware B-rep Reconstruction from Point Clouds (2026)

- **Source:** `Crossref / SSRN`
- **Link:** https://doi.org/10.2139/ssrn.6172545
- **Contribution:** Presents a learning-based framework that reconstructs complete, topologically consistent B-Rep models from point clouds by integrating parametric surface fitting with geometric distance field prediction.
- **Why It Matters:** Directly reconstructs the final B-Rep data structure (surface patches, edge curves, vertices, connectivity) from point cloud input, fulfilling the reconstruction task.
- **Evidence:** Abstract states the method recovers 'edge curves, vertex locations, and their connectivity' to produce a 'complete and topologically consistent B-rep model'.

### 4. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Develops an autoregressive Transformer that uses a unified tokenization scheme for geometry and topology, generating B-Reps via next-token prediction following a face adjacency graph traversal.
- **Why It Matters:** Directly generates B-Reps end-to-end. The unified tokenization represents both geometric primitives and topological references, producing the final data structure.
- **Evidence:** Abstract explicitly states the model 'autoregressively generates B-Reps' and outputs 'B-Reps with high quality and validity'.

### 5. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Proposes a novel representation encoding B-Rep geometry as SDF/UDFs and a multi-branch latent diffusion model to jointly generate these functions, which are then converted to a faceted B-Rep model.
- **Why It Matters:** End-to-end generation of a (faceted) B-Rep model via a modern diffusion architecture. The output is a watertight CAD B-Rep model derived from the generated distance functions.
- **Evidence:** Abstract describes generating SDF and per-face UDFs via diffusion, then converting them to a 'watertight CAD B-Rep model' using an extended Marching Cubes algorithm.

### 6. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Introduces a single-stage autoregressive framework using a decoder-only Transformer and a novel Voronoi Half-Patch (VHP) representation to unify geometric attributes and topological relations in a compact sequence.
- **Why It Matters:** Directly generates complete B-Rep models autoregressively. The VHP representation allows a unified encoding of geometry and topology for direct generation.
- **Evidence:** Abstract states the framework 'autoregressively predict[s] these tokens, which are subsequently mapped... and decoded into complete B-rep models'.

### 7. DTGBrepGen: A Novel B-rep Generative Model through Decoupling Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2503.13110v1
- **Contribution:** Proposes a topology-geometry decoupled framework that first generates valid topological structures, then uses Transformer-based diffusion models to sequentially generate vertex, edge, and face geometries (B-splines).
- **Why It Matters:** Directly generates B-Rep models. The method explicitly separates topology and geometry generation but outputs the final combined B-Rep structure.
- **Evidence:** Abstract describes generating 'topological structures' and then 'sequential geometry generation' resulting in 'realistic B-reps'.

## Key Observations

- Dominant architectures are autoregressive Transformers (BrepARG, AutoBrep, BrepGPT) and diffusion models (HiDiGen, DTGBrepGen, BR-DF), often combined.
- A central challenge is representing the coupled discrete topology and continuous geometry; solutions include holistic token sequences (BrepARG), decoupled pipelines (DTGBrepGen, HiDiGen), and unified local units (Voronoi Half-Patch in BrepGPT).
- Generation is increasingly treated as an end-to-end sequence prediction problem, leveraging the success of large language models.
- Several papers (Point2Brep) specifically address the reconstruction task from point clouds, integrating learning with explicit geometric reasoning.
- Topological validity is a key metric, with methods explicitly modeling constraints (HiDiGen) or decoupling topology generation (DTGBrepGen) to ensure watertightness.
