## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first method to encode B-rep geometry and topology into a holistic token sequence, enabling autoregressive generation via a transformer architecture.
- **Why It Matters:** Directly generates B-Reps by constructing a hierarchical token sequence of geometry and topology, using a decoder-only transformer for next-token prediction. Does not rely on operation sequences.
- **Evidence:** Abstract states it encodes B-rep's geometry and topology into a holistic token sequence for sequence-based generation.

### 2. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Introduces BrepGPT, a single-stage autoregressive framework using a Voronoi Half-Patch (VHP) representation and dual VQ-VAEs to encode B-reps into a compact sequence for a decoder-only Transformer.
- **Why It Matters:** Directly generates complete B-rep models autoregressively from a unified local unit representation. Supports unconditional and conditional generation (point clouds, text, images).
- **Evidence:** Abstract describes a framework for B-rep generation that outputs complete B-rep models, addressing the coupling of geometry and topology.

### 3. GraphBrep: Learning B-Rep in Graph Structure for Efficient CAD Generation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2507.04765v1
- **Contribution:** Proposes GraphBrep, a model that explicitly represents B-Rep topology as an undirected weighted graph and uses a graph diffusion model to learn topology conditioned on surface features.
- **Why It Matters:** Direct B-Rep generation model that explicitly learns compact topology via a graph diffusion model, reducing computational redundancy compared to methods that implicitly embed topology in geometry.
- **Evidence:** Abstract states it is a B-Rep generation model for direct CAD generation, learning joint distribution of geometry and topology.

### 4. HoLa: B-Rep Generation using a Holistic Latent Representation (2025)

- **Source:** `Semantic Scholar / ACM Transactions on Graphics`
- **Link:** https://www.semanticscholar.org/paper/6629d249c1e35fbd5053208cf975e9c2bae98305
- **Contribution:** Introduces a holistic latent (HoLa) space that unifies continuous geometric properties and discrete topological relations of B-Reps, enabling a diffusion-based generator for various inputs.
- **Why It Matters:** Learns and generates CAD models as B-Reps directly, reformulating topology learning as geometric reconstruction. A diffusion model generates B-Reps from point clouds, images, sketches, or text.
- **Evidence:** Abstract describes a novel representation for learning and generating CAD models as B-Reps with a diffusion-based generator.
