## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first method to encode B-rep geometry and topology into a holistic token sequence, enabling autoregressive generation via a transformer decoder.
- **Why It Matters:** Directly generates B-Reps end-to-end by constructing a sequence of geometry, position, and face index tokens. Uses a modern autoregressive transformer architecture, outputting the complete B-Rep data structure without step-by-step modeling history.
- **Evidence:** Abstract explicitly states encoding of geometry and topology into token sequences and autoregressive generation via next-token prediction.

### 2. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Introduces a hierarchical diffusion framework that decouples geometry modeling, first establishing a topological scaffold (face-edge incidence) then refining face surfaces and vertex positions with Transformer-based diffusion modules.
- **Why It Matters:** Directly generates valid B-Rep structures with explicit topological constraints using a modern diffusion model. Output includes faces, edges, vertices, and their connectivity, not a construction sequence.
- **Evidence:** Abstract describes generation of face-edge incidence relations, face proxies, edge curves, and precise geometry via diffusion, ensuring topological soundness.

### 3. Point2Brep: Geometry-Aware B-rep Reconstruction from Point Clouds (2026)

- **Source:** `Crossref / SSRN`
- **Link:** https://doi.org/10.2139/ssrn.6172545
- **Contribution:** Presents a learning-based framework that reconstructs complete, topologically consistent B-rep models from point clouds by integrating learned surface segmentation, parametric surface fitting, and geometric reasoning of edges and vertices.
- **Why It Matters:** Direct B-Rep reconstruction from point cloud input. Outputs the final B-Rep data structure (faces, edges, vertices, connectivity) via a pipeline combining learning and explicit geometric reasoning, not a modeling history.
- **Evidence:** Abstract states reconstruction of 'complete and topologically consistent B-rep models' and recovery of 'edge curves, vertex locations, and their connectivity'.

### 4. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Develops an autoregressive Transformer model that uses a unified tokenization scheme encoding both geometric primitives (as latent tokens) and topological references, generating B-Reps via next-token prediction.
- **Why It Matters:** Direct end-to-end generation of B-Reps with precise geometry and watertight topology. The model autoregressively outputs a sequence representing the B-Rep's face adjacency graph, not a construction tree.
- **Evidence:** Abstract describes unified tokenization of geometry and topology and autoregressive generation via next-token prediction for B-Reps.

### 5. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Proposes a novel B-Rep representation using volumetric distance functions (SDF for mesh, per-face UDFs for topology) and a multi-branch latent diffusion model for joint generation of SDF and UDFs.
- **Why It Matters:** Generates faceted B-Rep models via a diffusion model that outputs distance fields, which are then converted to a watertight B-Rep. The output is the final B-Rep structure, not a sequence of operations.
- **Evidence:** Abstract states encoding of B-Rep vertices, edges, faces, and topology via distance functions and generation via a diffusion model, with conversion to B-Rep.

### 6. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Introduces a single-stage autoregressive framework using a Voronoi Half-Patch (VHP) representation to unify geometric attributes and topological relations, encoded into tokens for a decoder-only Transformer.
- **Why It Matters:** Directly generates complete B-rep models (faces, edges, vertices, topology) autoregressively. The VHP representation unifies geometry and topology in a single format, avoiding multi-stage cascades.
- **Evidence:** Abstract describes autoregressive prediction of tokens mapped to vertex-based features and decoded into complete B-rep models.

### 7. DTGBrepGen: A Novel B-rep Generative Model through Decoupling Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2503.13110v1
- **Contribution:** Proposes a topology-geometry decoupled framework: first generates valid topological structures (edge-face/edge-vertex adjacency), then uses Transformer-based diffusion models to sequentially generate vertex coordinates, edge geometries (B-splines), and face geometries.
- **Why It Matters:** Direct B-rep generation that explicitly models topology and geometry separately but outputs the unified B-Rep data structure. Uses diffusion models for geometry, not a construction sequence.
- **Evidence:** Abstract describes two-stage process for topology and sequential geometry generation via diffusion models to produce B-reps.

### 8. GraphBrep: Learning B-Rep in Graph Structure for Efficient CAD Generation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2507.04765v1
- **Contribution:** Presents a graph diffusion model that explicitly represents and learns compact surface topology as an undirected weighted graph, conditioned on surface features, to determine connectivity between primitive surfaces.
- **Why It Matters:** Direct B-Rep generation that models the joint distribution of geometry and topology using a graph diffusion model. Outputs B-Reps with surfaces, edges, and vertices.
- **Evidence:** Abstract states the model learns B-Rep in a graph structure for direct generation, using a graph diffusion model to learn topology.

### 9. HoLa: B-Rep Generation using a Holistic Latent Representation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2504.14257v3
- **Contribution:** Introduces a holistic latent representation that unifies continuous geometric properties of surfaces/curves and discrete topological relations by deriving curve geometries from surface pairs via a neural intersection network, enabling diffusion-based generation from various inputs.
- **Why It Matters:** Direct B-Rep generation from a compact latent space that encodes full B-Rep (surfaces, curves, vertices, topology). Uses a diffusion-based generator, outputting the final B-Rep structure, not a history.
- **Evidence:** Abstract describes a holistic latent space defined on surfaces that encodes full B-Rep and a diffusion-based generator for B-Rep generation.

## Key Observations

- Dominant architectures are autoregressive transformers (BrepARG, AutoBrep, BrepGPT) and diffusion models (HiDiGen, BR-DF, DTGBrepGen, GraphBrep), often combined.
- A central challenge is representing the joint distribution of discrete topology and continuous geometry; methods address this via holistic token sequences (BrepARG), decoupled pipelines (DTGBrepGen), unified latent spaces (HoLa), or graph structures (GraphBrep).
- Recent trend toward 'direct' single-stage or end-to-end generation, moving away from multi-stage cascades that accumulate error (e.g., BrepGPT emphasizes single-stage).
- Topology is increasingly modeled explicitly via constraints (HiDiGen), graphs (GraphBrep), or derived from geometry (HoLa's neural intersection), rather than being implicitly embedded.
- High validity rates (e.g., HoLa reports 82% vs. ~50% prior) are a key metric, indicating progress on generating topologically sound B-Reps.
- Input conditioning is versatile: unconditional generation, point clouds (Point2Brep), category labels, text, images (HoLa, BrepGPT).

## Open Questions

- How to effectively scale diffusion or transformer models to industrial-scale CAD datasets with extreme geometric diversity?
- Is there a fundamental trade-off between decoupling topology/geometry for control and joint modeling for coherence?
- How to incorporate user constraints or partial specifications interactively during direct generation?
