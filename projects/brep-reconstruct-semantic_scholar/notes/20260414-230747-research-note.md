## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first autoregressive transformer model for B-Rep generation by encoding geometry and topology into a unified holistic token sequence.
- **Why It Matters:** Directly generates B-Reps via next-token prediction on a sequence representing faces, edges, and vertices. Output is the B-Rep data structure, not a construction history.
- **Evidence:** Abstract states it encodes B-rep's geometry and topology into a holistic token sequence for sequence-based generation with an autoregressive architecture.

### 2. Flatten The Complex: Joint B-Rep Generation via Compositional k-Cell Particles (2026)

- **Source:** `Semantic Scholar / arXiv.org`
- **Link:** https://www.semanticscholar.org/paper/e4aa02b83ff20ee5ac9412b171a55474e74591b1
- **Contribution:** Introduces a paradigm reformulating B-Reps into sets of compositional k-cell particles and uses a multi-modal flow matching framework for joint generation of topology and geometry.
- **Why It Matters:** Enables joint generation of B-Rep topology and geometry with global context, supporting unconditional generation and reconstruction from point clouds or single views.
- **Evidence:** Abstract describes encoding each topological entity as a composition of particles and synthesizing particle sets using flow matching for B-Rep generation and reconstruction.

### 3. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Proposes a hierarchical diffusion framework that decouples geometry modeling into stages guided by explicitly modeled topological constraints.
- **Why It Matters:** Directly generates B-Rep structures by first establishing a topological scaffold, then refining geometry with Transformer-based diffusion modules.
- **Evidence:** Abstract states the approach establishes face-edge incidence relations first, then refines geometry with diffusion modules to generate topologically sound CAD models.

### 4. Point2Brep: Geometry-Aware B-rep Reconstruction from Point Clouds (2026)

- **Source:** `Crossref / Crossref | OpenAlex`
- **Link:** https://doi.org/10.2139/ssrn.6172545
- **Contribution:** Presents a geometry-aware framework that reconstructs complete, topologically consistent B-Rep models from point clouds by integrating learning-based inference with parametric modeling and geometric reasoning.
- **Why It Matters:** Direct B-Rep reconstruction from unstructured point clouds. Outputs faces, edges, vertices, and their connectivity.
- **Evidence:** Abstract describes a two-stage pipeline: segmenting point clouds into surface patches, then predicting geometric distance fields to recover edges, vertices, and connectivity.

### 5. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Presents an autoregressive Transformer model that generates B-Reps end-to-end using a unified tokenization scheme for geometry and topology.
- **Why It Matters:** Directly generates B-Reps via autoregressive next-token prediction. Token sequence follows a breadth-first traversal of the face adjacency graph.
- **Evidence:** Abstract states it employs a unified tokenization encoding geometric primitives and structural relationships, generating neighboring faces and edges progressively.

### 6. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Introduces BR-DF, a novel geometric representation encoding B-Reps as signed distance functions (SDF) and per-face unsigned distance functions (UDFs), with a multi-branch latent diffusion model for generation.
- **Why It Matters:** Generates B-Reps via diffusion on a volumetric distance function representation, which is then converted to a faceted B-Rep model.
- **Evidence:** Abstract describes encoding surface mesh as SDF and B-Rep elements as per-face UDFs, using a diffusion model to jointly generate SDF and UDFs for conversion to B-Rep.

### 7. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Proposes a single-stage autoregressive framework using a Voronoi Half-Patch (VHP) representation and dual VQ-VAEs to encode B-reps into a compact token sequence for generation.
- **Why It Matters:** Directly generates complete B-Rep models autoregressively. Supports unconditional and conditional generation (point clouds, text, images).
- **Evidence:** Abstract describes decomposing B-reps into VHP units, encoding them into tokens, and using a decoder-only Transformer for autoregressive prediction.

### 8. BrepGiff: Lightweight Generation of Complex B-rep with 3D GAT Diffusion (2025)

- **Source:** `Semantic Scholar / Computer Vision and Pattern Recognition`
- **Link:** https://www.semanticscholar.org/paper/efb93c0a49f2eec36381ff7d88043a0e732ba627
- **Contribution:** Introduces a lightweight generation method for complex B-rep models using a 3D Graph Diffusion process with a Graph Attention Network (GAT).
- **Why It Matters:** Direct generation of B-Rep CAD models by converting them to a 3D graph representation and applying a degree-guided diffusion process.
- **Evidence:** Abstract states it transfers B-rep models into 3D graphs and applies GAT to enforce topological constraints during diffusion for generation.

## Key Observations

- Dominant architectures are autoregressive Transformers (BrepARG, AutoBrep, BrepGPT) and diffusion models (HiDiGen, BR-DF, BrepGiff), indicating a shift from graph-based to sequence- and diffusion-based generation.
- A key trend is the development of unified representations that jointly encode topology and geometry, such as holistic token sequences, k-cell particles, and distance functions, to enable end-to-end generation.
- Several methods explicitly decouple topology and geometry generation into hierarchical stages (e.g., HiDiGen's topological scaffold first) to improve validity and manage complexity.
- Conditional generation from point clouds (Point2Brep) and other modalities (BrepGPT) is actively explored, expanding beyond unconditional synthesis.
- The field is rapidly advancing, with most core papers from 2025-2026, reflecting very recent innovation.
