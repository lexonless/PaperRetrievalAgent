## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first method to encode B-rep geometry and topology into a holistic token sequence, enabling autoregressive generation with a Transformer.
- **Why It Matters:** Directly generates B-Reps end-to-end via next-token prediction on a unified sequence representation. Does not use operation sequences.
- **Evidence:** Abstract states it encodes B-rep into geometry, position, and face index tokens, constructs a hierarchical sequence, and uses a decoder-only Transformer for generation.

### 2. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Introduces a hierarchical diffusion framework that decouples geometry modeling, first establishing a topological scaffold then refining geometry with Transformer-based diffusion modules.
- **Why It Matters:** Directly generates valid B-Rep structures using diffusion models guided by explicit topological constraints. Output is a B-Rep model.
- **Evidence:** Abstract describes a two-stage process: generating face-edge incidence relations, then refining face surfaces and vertex positions with diffusion, enforcing edge-vertex adjacencies.

### 3. Point2Brep: Geometry-Aware B-rep Reconstruction from Point Clouds (2026)

- **Source:** `Crossref / SSRN`
- **Link:** https://doi.org/10.2139/ssrn.6172545
- **Contribution:** Presents a learning-based framework that reconstructs complete, topologically consistent B-rep models from point clouds by integrating learning with explicit parametric modeling and geometric reasoning.
- **Why It Matters:** Direct neural reconstruction of B-Rep from point cloud input. Output is the final B-Rep data structure, not a construction history.
- **Evidence:** Abstract describes a two-stage pipeline: segmenting point clouds into surface patches, then predicting continuous distance fields to recover edges, vertices, and connectivity.

### 4. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Proposes a Transformer model that autoregressively generates B-Reps using a unified tokenization scheme encoding both geometric primitives and topological references.
- **Why It Matters:** End-to-end generation of B-Reps with precise geometry and watertight topology via next-token prediction. Sequence order follows face adjacency graph traversal.
- **Evidence:** Abstract states it encodes geometric primitives as latent tokens and structural relationships as topological reference tokens, generating faces and edges progressively.

### 5. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Introduces a volumetric distance function representation for B-Reps (BR-DF) and a multi-branch latent diffusion model for joint generation of SDF and per-face UDFs.
- **Why It Matters:** Generates faceted B-Rep models via a diffusion model operating on a novel volumetric representation. Output is converted directly to a watertight B-Rep.
- **Evidence:** Abstract describes encoding surface mesh as SDF and B-Rep elements as per-face UDFs, using a latent diffusion model with a 3D U-Net backbone.

### 6. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Presents a single-stage autoregressive framework using a novel Voronoi Half-Patch (VHP) representation and dual VQ-VAEs to encode topology and geometry into a compact sequence.
- **Why It Matters:** Directly generates complete B-Rep models autoregressively from a unified local unit representation. Supports unconditional and conditional generation.
- **Evidence:** Abstract describes decomposing B-reps into VHP units, encoding them into vertex-based tokens with VQ-VAEs, and using a decoder-only Transformer for prediction.

### 7. CADDreamer: CAD Object Generation from Single-view Images (2025)

- **Source:** `CVPR / arXiv`
- **Link:** http://arxiv.org/abs/2502.20732
- **Contribution:** Introduces a primitive-aware multi-view diffusion model to generate B-rep CAD objects from a single image, followed by geometric optimization and topology-preserving extraction.
- **Why It Matters:** Generates a complete and seamless B-Rep model from an image input using a diffusion-based approach. Output is a structured B-Rep, not a mesh or program.
- **Evidence:** Abstract states it infers multi-view normal and semantic maps, reconstructs a mesh with primitive labels, and applies optimization to produce a final B-rep.

### 8. DTGBrepGen: A Novel B-rep Generative Model through Decoupling Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2503.13110v1

- **Why It Matters:** Directly generates B-Rep models by explicitly modeling topology and geometry in separate stages. Output is a B-Rep with B-spline faces.

## Key Observations

- The field is highly active in 2025-2026, with a clear trend towards autoregressive Transformer and diffusion-based generative models.
- A major methodological theme is the creation of unified sequential representations (tokens) that jointly encode B-Rep topology and geometry, enabling the use of established sequence models.
- Many approaches adopt a hierarchical or decoupled strategy, often generating a topological scaffold first before refining geometry, to manage the complexity of joint topology-geometry generation.
- Direct reconstruction from point clouds appears less common than unconditional or image-conditioned generation among the most recent works.
- There is a strong emphasis on ensuring topological validity and watertightness in the generated outputs, often through explicit constraints or multi-stage pipelines.

## Open Questions

- How can models better handle the generation of complex, high-genus topology or models with many faces efficiently?
- What are the fundamental limits of sequential representations for highly irregular B-Rep structures?
- Can a single model generalize effectively across diverse CAD domains (e.g., mechanical, architectural, organic) without domain-specific tuning?
- How can reconstruction from sparse or noisy real-world scans (beyond clean point clouds) be made more robust?
- Is there a trade-off between the decoupled topology-first approaches and fully joint generation in terms of output diversity and novelty?
