## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first autoregressive transformer that encodes B-Rep geometry and topology into a unified holistic token sequence, enabling sequence-based generation via next-token prediction.
- **Why It Matters:** Directly generates B-Reps end-to-end by predicting geometry, position, and face-index tokens. Outputs the complete B-Rep structure without modeling sequences.
- **Evidence:** Abstract states it encodes B-rep's geometry and topology into a holistic token sequence for autoregressive generation.

### 2. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Introduces BR-DF, a novel representation encoding B-Rep geometry as an SDF and topology via per-face UDFs, with a multi-branch latent diffusion model for joint generation.
- **Why It Matters:** Directly outputs a faceted B-Rep model from generated SDF/UDFs via a modified Marching Cubes. Uses a neural diffusion process for end-to-end generation.
- **Evidence:** Abstract describes encoding B-Rep into distance functions and a diffusion model for generation, converting to a faceted B-Rep.

### 3. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Presents a single-stage autoregressive framework using a Voronoi Half-Patch representation and dual VQ-VAEs to encode B-Reps into tokens for a decoder-only Transformer.
- **Why It Matters:** Directly generates complete B-Rep models from tokens, unifying geometric attributes and topological relations. Supports unconditional and conditional generation.
- **Evidence:** Abstract describes a single-stage autoregressive framework for B-rep generation using a novel VHP representation and Transformer.

### 4. GraphBrep: Learning B-Rep in Graph Structure for Efficient CAD Generation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2507.04765v1
- **Contribution:** Proposes a B-Rep generation model that explicitly represents topology as an undirected weighted graph and uses a graph diffusion model conditioned on surface features.
- **Why It Matters:** Directly generates B-Reps by learning the joint distribution of geometry and topology via a variational autoencoder and graph diffusion, avoiding sequential modeling.
- **Evidence:** Abstract states it is a direct B-Rep generation model that learns compact topology via a graph diffusion model.

### 5. BrepGen: A B-rep Generative Diffusion Model with Structured Latent Geometry (2024)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2401.15563v3
- **Contribution:** Introduces a diffusion-based generative model that represents a B-Rep as a hierarchical tree of primitives (faces, edges, vertices) and uses Transformer-based diffusion to denoise node features.
- **Why It Matters:** Directly outputs a B-Rep CAD model. Topology is implicitly represented by node duplication and recovered during denoising/merging.
- **Evidence:** Abstract presents a diffusion approach that directly outputs a B-rep model via a structured latent tree and transformer-based diffusion.

### 6. Split-and-Fit: Learning B-Reps via Structure-Aware Voronoi Partitioning (2024)

- **Source:** `OpenAlex (DOI: 10.1145/3658155)`
- **Link:** https://doi.org/10.1145/3658155
- **Contribution:** Proposes a top-down, structure-aware method using a neural network (NVD-Net) to predict a Voronoi diagram of B-Rep primitives from point clouds or distance fields, then fits primitives within partitions.
- **Why It Matters:** Acquires B-Reps (parametric surfaces, curves, vertices) from input point clouds. It is a neural reconstruction method that directly outputs the B-Rep structure.
- **Evidence:** Abstract describes a neural network for predicting Voronoi partitions to acquire B-Reps from point clouds.

### 7. ComplexGen: CAD Reconstruction by B-Rep Chain Complex Generation (2022)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2205.14573v1
- **Contribution:** Frames B-Rep reconstruction as detecting geometric primitives (vertices, edges, surfaces) and their correspondence, modeled as a chain complex, using a sparse CNN encoder and tri-path transformer decoder.
- **Why It Matters:** Directly reconstructs B-Rep models from point clouds. Outputs primitives and their topological relationships via a neural network and subsequent global optimization.
- **Evidence:** Abstract views B-Rep reconstruction as detection of primitives and uses a neural framework for generation.

### 8. SolidGen: An Autoregressive Model for Direct B-rep Synthesis (2022)

- **Source:** `OpenAlex (arXiv)`
- **Link:** http://arxiv.org/abs/2203.13944
- **Contribution:** Presents an autoregressive neural network that directly synthesizes B-Reps by predicting vertices, edges, and faces using Transformer and pointer networks, without CAD sequence supervision.
- **Why It Matters:** Directly generates B-Reps end-to-end from a learned distribution. Explicitly avoids using sketch-and-extrude sequences.
- **Evidence:** Abstract describes an autoregressive network that models the B-rep directly by predicting vertices, edges, and faces.

## Key Observations

- Representation Strategies: Methods diverge into sequential tokenization (BrepARG, BrepGPT), hierarchical trees (BrepGen), graph structures (GraphBrep), volumetric fields (BR-DF), and primitive detection with complex modeling (ComplexGen, Split-and-Fit).
- Architectural Trends: Autoregressive Transformers (2022-2026) and Diffusion Models (2024-2025) are dominant for generation. Graph Neural Networks and VAEs appear in hybrid or explicit topology modeling.
- Joint Geometry-Topology Handling: A central challenge. Solutions include implicit topology via token sequences or node duplication, explicit graph learning, and two-stage pipelines (detect then connect).
- Input Flexibility: Papers cover unconditional generation, point cloud reconstruction, and conditioning on labels, text, or images.
