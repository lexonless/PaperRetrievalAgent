- **Why It Matters:** Directly generates B-Rep data structures by unifying geometry and topology in a token sequence. Uses a modern neural architecture (decoder-only transformer) and outputs the final B-Rep, not operation sequences.
- **Evidence:** Abstract states it encodes B-rep's geometry and topology into a holistic token sequence representation for autoregressive generation.

### 2. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Introduces BR-DF, a novel representation encoding B-Rep geometry as SDF and topology via per-face UDFs, and uses a multi-branch latent diffusion model for joint generation.
- **Why It Matters:** Directly outputs faceted B-Rep models from generated distance functions. Employs a modern diffusion architecture for unconditional generation, achieving 100% success rate in producing valid B-Reps.
- **Evidence:** Abstract describes encoding B-Rep into SDF/UDF and using a diffusion model to generate them, which are then converted to watertight CAD B-Rep models.

### 3. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Presents BrepGPT, a single-stage autoregressive framework using a novel Voronoi Half-Patch (VHP) representation to unify geometry and topology, decoded by a transformer.
- **Why It Matters:** Performs unconditional B-Rep generation and also supports conditional generation from point clouds, images, and text. Outputs complete B-Rep models directly, not operation histories.
- **Evidence:** Abstract describes a framework for B-rep generation that decomposes B-reps into unified local units (VHP) and uses an autoregressive transformer.

### 4. HoLa: B-Rep Generation using a Holistic Latent Representation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2504.14257v3
- **Contribution:** Introduces a holistic latent (HoLa) space that unifies continuous geometric properties and discrete topological relations of B-Reps, enabling a diffusion-based generator for various inputs.
- **Why It Matters:** Directly generates B-Reps (surfaces, curves, vertices, topology) from point clouds, images, sketches, or text. Reformulates topology learning as geometric reconstruction, avoiding multi-step pipelines.
- **Evidence:** Abstract states it introduces a representation for learning and generating CAD models as boundary representations (B-Reps) using a holistic latent space and diffusion generator.

### 5. Split-and-Fit: Learning B-Reps via Structure-Aware Voronoi Partitioning (2024)

- **Source:** `OpenAlex`
- **Link:** https://doi.org/10.1145/3658155
- **Contribution:** Proposes a two-step method: a neural network (NVD-Net) predicts a Voronoi diagram from a point cloud/distance field, then fits primitives within each partition to construct B-Reps.
- **Why It Matters:** Acquires B-Reps (parametric surfaces, curves, vertices) directly from input point clouds. It is a reconstruction method that outputs the final B-Rep data structure, not a construction history.
- **Evidence:** Abstract describes a method for acquiring boundary representations (B-Reps) from input point clouds via neural Voronoi diagram prediction and primitive fitting.
