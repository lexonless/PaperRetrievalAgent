## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first autoregressive model to encode B-rep geometry and topology into a holistic token sequence, enabling sequence-based generation with a transformer decoder.
- **Why It Matters:** Directly generates B-Reps end-to-end by tokenizing faces, edges, and topology into a single sequence for next-token prediction. Does not rely on operation sequences.
- **Evidence:** Abstract states it encodes B-rep's geometry and topology into a holistic token sequence for autoregressive generation.

### 2. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Introduces a hierarchical diffusion framework that decouples topology and geometry generation, using Transformer-based diffusion modules guided by explicit topological constraints (face-edge incidence, edge-vertex adjacency).
- **Why It Matters:** Directly generates topologically sound B-Rep models via a diffusion process, explicitly modeling discrete topology and continuous geometry. Unconditional generation.
- **Evidence:** Abstract describes generating 'topologically sound CAD models' by first establishing topological scaffolds then refining geometry with diffusion.

### 3. Point2Brep: Geometry-Aware B-rep Reconstruction from Point Clouds (2026)

- **Source:** `Crossref / SSRN`
- **Link:** https://doi.org/10.2139/ssrn.6172545
- **Contribution:** Presents a two-stage framework that integrates learning-based surface segmentation with geometric reasoning to reconstruct complete, topologically consistent B-rep models from noisy point clouds.
- **Why It Matters:** Direct B-Rep reconstruction from point cloud input. Outputs edge curves, vertex locations, and connectivity, not operation sequences.
- **Evidence:** Abstract describes recovering edge curves, vertex locations, and connectivity from point clouds via learned distance fields and geometric reasoning.

### 4. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Develops an autoregressive Transformer that tokenizes both geometry and topology into a unified sequence, generating B-Reps progressively via next-token prediction.
- **Why It Matters:** End-to-end direct generation of B-Reps with watertight topology. Uses a unified tokenization scheme for geometry and topological references.
- **Evidence:** Abstract states it 'autoregressively generates B-Reps' with a unified tokenization encoding geometry and topology.

### 5. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Proposes a novel B-Rep representation using signed distance functions (SDF) for mesh geometry and per-face unsigned distance functions (UDF) for topology, with a multi-branch latent diffusion model for joint generation.
- **Why It Matters:** Direct neural generation of B-Reps via diffusion on a volumetric distance function representation, which is then converted to a faceted B-Rep model.
- **Evidence:** Abstract describes a diffusion model for jointly generating SDF and per-face UDFs, converted to a watertight B-Rep.

### 6. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Introduces a single-stage autoregressive framework using a Voronoi Half-Patch (VHP) representation to unify geometric and topological features, enabling generation via a decoder-only Transformer.
- **Why It Matters:** Direct unconditional and conditional B-Rep generation from a compact sequential encoding. Does not involve operation sequences.
- **Evidence:** Abstract presents an autoregressive framework that decodes tokens into complete B-rep models.

### 7. CADDreamer: CAD Object Generation from Single-view Images (2025)

- **Source:** `CVPR`
- **Link:** https://doi.org/10.1109/cvpr52734.2025.01998
- **Contribution:** Uses a primitive-aware multi-view diffusion model to infer normal and semantic maps from a single image, then reconstructs and optimizes a mesh into a complete B-rep.
- **Why It Matters:** Direct B-Rep reconstruction/generation from a single image, outputting a structured B-Rep model. Not a sequential operation history.
- **Evidence:** Abstract describes generating 'boundary representations (B-rep) of CAD objects from a single image' via diffusion and optimization.

### 8. DTGBrepGen: A Novel B-rep Generative Model through Decoupling Topology and Geometry (2025)

- **Source:** `arXiv / CVPR`
- **Link:** http://arxiv.org/abs/2503.13110v1
- **Contribution:** Proposes a topology-geometry decoupled framework that first generates valid topological structures, then uses Transformer-based diffusion models to sequentially generate vertex, edge, and face geometries.
- **Why It Matters:** Direct B-Rep generation by explicitly modeling topology and geometry separately with diffusion models. Output is a B-Rep data structure.
- **Evidence:** Abstract describes generating topological structures then using diffusion for geometry (vertex coordinates, edge geometries, face B-splines).

## Key Observations

- Representation Strategies: Core methods represent B-Reps for neural networks via (1) holistic token sequences (BrepARG, AutoBrep), (2) hierarchical decoupled representations (HiDiGen, DTGBrepGen), (3) volumetric distance functions (BR-DF), and (4) local unified patches (BrepGPT).
- Architectural Trends: Autoregressive transformers and diffusion models are dominant for generation, often combined with explicit topological constraint modeling to ensure validity.
- Input Modalities: Methods support unconditional generation, reconstruction from point clouds (Point2Brep), and generation from single images (CADDreamer).
- Topology vs. Geometry: A clear trend is the explicit decoupling and joint modeling of discrete topology (adjacency graphs) and continuous geometry (surfaces, curves), often in a two-stage or hierarchical process.
- Validity Focus: Recent papers strongly emphasize generating topologically valid and watertight B-Reps, moving beyond pure geometric accuracy.
