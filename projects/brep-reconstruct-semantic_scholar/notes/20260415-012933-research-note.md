## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first method to encode B-rep geometry and topology into a holistic token sequence for autoregressive generation using a transformer, enabling sequence-based B-rep generation.
- **Why It Matters:** Directly generates B-Reps via an autoregressive transformer architecture. Output is a B-Rep data structure from a learned token sequence, with no operation history.
- **Evidence:** Abstract explicitly describes encoding geometry and topology into tokens for next-token prediction with a decoder-only transformer.

### 2. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Introduces a hierarchical diffusion framework that decouples geometry modeling, first establishing a topological scaffold and then refining geometry with Transformer-based diffusion modules.
- **Why It Matters:** Direct B-Rep generation via a diffusion model. Output is a valid B-Rep with explicit topological constraints, not a modeling sequence.
- **Evidence:** Abstract states the framework generates valid B-rep structures with topology and geometry using diffusion and Transformers.

### 3. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Presents a Transformer model that autoregressively generates B-Reps end-to-end using a unified tokenization scheme encoding both geometry and topology.
- **Why It Matters:** Direct, end-to-end B-Rep generation. Progressively generates neighboring faces and edges with their topological structure via next-token prediction.
- **Evidence:** Abstract describes unified tokenization of geometric primitives and topological references, with generation following a face adjacency graph traversal.

### 4. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Proposes a novel B-Rep representation using volumetric distance functions (SDF and per-face UDFs) and a multi-branch latent diffusion model for joint generation.
- **Why It Matters:** Direct neural generation of faceted B-Rep models. Output is a watertight CAD B-Rep model (vertices, edges, faces, topology) via a diffusion process.
- **Evidence:** Abstract states the method uses a latent diffusion model to generate SDF and UDFs, which are converted to a watertight B-Rep model.

### 5. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Introduces a single-stage autoregressive framework using a Voronoi Half-Patch representation and a decoder-only Transformer to generate complete B-rep models.
- **Why It Matters:** Direct B-Rep generation for unconditional and conditional tasks. Outputs complete B-rep models (geometry and topology) from a sequence of tokens.
- **Evidence:** Abstract describes unifying geometric attributes and topological relations in a single format, with autoregressive token prediction.

## Key Observations

- The field of direct neural B-Rep generation is active, with a clear trend towards modern generative architectures: Diffusion models (HiDiGen, BR-DF, HoLa), Autoregressive Transformers (AutoBrep, BrepARG, BrepGPT), and Graph Neural Networks/Diffusion (GraphBrep, BrepGiff).
- A central challenge being addressed is the joint modeling of discrete topology and continuous geometry. Strategies include decoupled pipelines (DTGBrepGen), holistic latent spaces (HoLa), and unified token sequences (AutoBrep).
- Generation tasks are diverse, including unconditional generation, and conditioning on point clouds, images, text, and sketches (e.g., CADDreamer, HoLa).
- Validity (watertightness, topological soundness) is a key metric and design goal, with several papers reporting high validity rates (e.g., HoLa reports 82%).
