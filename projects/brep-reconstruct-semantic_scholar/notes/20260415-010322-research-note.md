- **Why It Matters:** Directly generates B-Reps end-to-end. Output is a sequence of tokens representing faces, edges, and topology, enabling sequence-based generative frameworks.
- **Evidence:** Abstract states it encodes B-rep's geometry and topology into a holistic token sequence for autoregressive generation.

### 2. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Introduces a hierarchical diffusion framework that decouples geometry modeling, first establishing a topological scaffold, then refining geometry with Transformer-based diffusion modules under explicit topological constraints.
- **Why It Matters:** Direct B-Rep generation using diffusion models. Ensures topological validity by modeling face-edge incidence relations and edge-vertex adjacencies explicitly.
- **Evidence:** Abstract describes generating valid B-Rep structures by decoupling topology and geometry with diffusion.

## Key Observations

- Dominant architectures are autoregressive Transformers (BrepARG, AutoBrep, BrepGPT) and diffusion models (HiDiGen, HoLa, BR-DF), often combined.
- A central challenge is jointly modeling discrete topology and continuous geometry. Strategies include holistic token sequences, decoupled pipelines, graph representations, and unified latent spaces.
- Representation innovation is key: papers propose novel encodings like holistic token sequences (BrepARG), Voronoi Half-Patches (BrepGPT), volumetric distance functions (BR-DF), and holistic latent spaces (HoLa).
- Validity is a major metric. Methods explicitly enforce topological constraints (HiDiGen), decouple topology generation (DTGBrepGen), or use representations guaranteeing convertibility (BR-DF).
- Input modalities are diverse: unconditional generation, point clouds (Point2Brep), single/multi-view images (CADDreamer, HoLa), and text (supporting paper).
