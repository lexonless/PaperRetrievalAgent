## Core Papers

### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first autoregressive transformer model that encodes B-Rep geometry and topology into a holistic token sequence, enabling end-to-end sequence-based generation.
- **Why It Matters:** Directly generates B-Rep as a token sequence via next-token prediction with a decoder-only transformer. Outputs final B-Rep structure, not a modeling history.
- **Evidence:** Abstract states it encodes B-Rep into geometry, position, and face index tokens, constructs a hierarchical sequence, and uses an autoregressive model for generation.

### 2. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Presents a Transformer model that autoregressively generates B-Reps using a unified tokenization scheme encoding both geometry and topology, focusing on watertight output.
- **Why It Matters:** End-to-end B-Rep generation via next-token prediction. Token sequence follows face adjacency graph traversal, progressively generating neighboring faces and edges.
- **Evidence:** Abstract describes unified tokenization of geometric primitives and topological references, with sequence order based on breadth-first traversal of the face adjacency graph.

### 3. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Introduces a single-stage autoregressive framework using a Voronoi Half-Patch (VHP) representation and dual VQ-VAEs to encode B-Reps into a compact sequence for transformer-based generation.
- **Why It Matters:** Direct B-Rep generation from tokens decoded into complete models. Framework supports unconditional and conditional generation (point clouds, text, images).
- **Evidence:** Abstract states VHP representation unifies geometric attributes and topological relations, and a decoder-only Transformer autoregressively predicts tokens mapped to B-Reps.

### 4. GraphBrep: Learning B-Rep in Graph Structure for Efficient CAD Generation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2507.04765v1
- **Contribution:** Proposes a B-Rep generation model that explicitly represents and learns compact topology via an undirected weighted graph, using a graph diffusion model conditioned on surface features.
- **Why It Matters:** Direct B-Rep generation model. Uses graph diffusion to learn topology, which then determines connectivity between primitive surfaces.
- **Evidence:** Abstract describes constructing a graph to represent surface topology and employing a graph diffusion model to learn topology conditioned on surface features.

### 5. HoLa: B-Rep Generation using a Holistic Latent Representation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2504.14257v3
- **Contribution:** Introduces a holistic latent (HoLa) space that unifies continuous geometric properties of B-Rep primitives and discrete topological relations, enabling a diffusion-based generator for various inputs.
- **Why It Matters:** Direct B-Rep generation/reconstruction from point clouds, images, sketches, or text. Latent space encodes full B-Rep (surfaces, curves, vertices, topology) via a neural intersection network.
- **Evidence:** Abstract states topology learning is reformulated as a geometric reconstruction problem; the latent space is defined only on surfaces but encodes the entire B-Rep model.

### 6. Split-and-Fit: Learning B-Reps via Structure-Aware Voronoi Partitioning (2024)

- **Source:** `SIGGRAPH`
- **Link:** https://doi.org/10.1145/3658155
- **Contribution:** Presents a top-down method for B-Rep acquisition from point clouds/distance fields using a neural network (NVD-Net) to predict a Voronoi diagram, followed by primitive fitting within partitions.
- **Why It Matters:** Direct B-Rep reconstruction. Outputs parametric surfaces, curves, and vertices. Method is structure-aware via Voronoi partitioning, not a bottom-up construction history.
- **Evidence:** Abstract describes a two-step split-and-fit process using a neural network to predict Voronoi diagrams, resulting in B-Reps consisting of parametric surfaces, curves, and vertices.

### 7. ComplexGen: CAD Reconstruction by B-Rep Chain Complex Generation (2022)

- **Source:** `SIGGRAPH`
- **Link:** https://doi.org/10.1145/3528223.3530078
- **Contribution:** Frames B-Rep reconstruction as the detection of geometric primitives (vertices, edges, surfaces) and their relationships, modeled as a chain complex, using a neural framework followed by global optimization.
- **Why It Matters:** Direct B-Rep reconstruction from point clouds. Uses a sparse CNN encoder and tri-path transformer decoder to generate primitives and relationships, then recovers a definite B-Rep chain complex via optimization.
- **Evidence:** Abstract describes a neural framework for generating geometric primitives and their mutual relationships, followed by optimization to recover a B-Rep chain complex.
