### 1. AutoRegressive Generation with B-rep Holistic Token Sequence Representation (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2601.16771v2
- **Contribution:** Proposes BrepARG, the first autoregressive transformer model that encodes B-Rep geometry and topology into a holistic token sequence, enabling sequence-based generation via next-token prediction.
- **Why It Matters:** Directly generates B-Rep data structures by constructing a hierarchical token sequence of geometry and face-index tokens. It is a pure autoregressive generation method, not reliant on operation sequences.
- **Evidence:** Abstract explicitly describes encoding faces, edges, vertices, and topology into a holistic token sequence and using a decoder-only transformer for generation.

### 2. HiDiGen: Hierarchical Diffusion for B-Rep Generation with Explicit Topological Constraints (2026)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2604.02847v1
- **Contribution:** Introduces a hierarchical diffusion framework that decouples geometry modeling, first establishing a topological scaffold (face-edge incidence) and then refining geometry with Transformer-based diffusion modules.
- **Why It Matters:** Directly generates B-Rep structures with explicit modeling of topological constraints (face-edge, edge-vertex) to ensure validity, using a modern diffusion architecture.
- **Evidence:** Abstract states the method generates face proxies and edge curves based on topological relations, then refines geometry, outputting topologically sound CAD models.

### 3. AutoBrep: Autoregressive B-Rep Generation with Unified Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2512.03018v1
- **Contribution:** Presents an autoregressive Transformer that uses a unified tokenization scheme for geometry and topology, generating B-Reps via breadth-first traversal of the face adjacency graph.
- **Why It Matters:** End-to-end generation of B-Reps with progressive output of faces and edges. Unifies geometric and topological tokens, directly producing the final data structure.
- **Evidence:** Abstract describes encoding geometric primitives as latent tokens and structural relationships as topological reference tokens, generating sequences autoregressively.

### 4. B-Rep Distance Functions (BR-DF): How to Represent a B-Rep Model by Volumetric Distance Functions? (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.14870v1
- **Contribution:** Proposes a novel B-Rep representation using volumetric distance functions (SDF for surface, per-face UDFs for topology) and a multi-branch latent diffusion model for joint generation.
- **Why It Matters:** Generates a faceted B-Rep model via a diffusion model that outputs SDF and UDFs, which are then converted to a watertight B-Rep. It is an end-to-end neural generation method.
- **Evidence:** Abstract states the method jointly generates SDF and per-face UDFs via diffusion, with a guaranteed conversion to a faceted B-Rep model.

### 5. BrepGPT: Autoregressive B-rep Generation with Voronoi Half-Patch (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2511.22171v1
- **Contribution:** Introduces a single-stage autoregressive framework using a Voronoi Half-Patch (VHP) representation and a decoder-only Transformer to generate complete B-Rep models from compact tokens.
- **Why It Matters:** Directly generates unified geometry and topology in a single autoregressive pass, avoiding multi-stage pipelines. Supports conditional generation from various inputs.
- **Evidence:** Abstract describes decomposing B-Reps into VHP units, encoding them into tokens, and using a Transformer to autoregressively predict tokens decoded into B-Reps.

### 6. DTGBrepGen: A Novel B-rep Generative Model through Decoupling Topology and Geometry (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2503.13110v1
- **Contribution:** Proposes a topology-geometry decoupled framework that first generates valid topological structures, then uses Transformer-based diffusion models to sequentially generate vertex, edge, and face geometries (as B-splines).
- **Why It Matters:** Explicitly generates topological adjacency relations before geometry, directly outputting a valid B-Rep. Uses diffusion models for the geometric stage.
- **Evidence:** Abstract outlines a two-stage process for topology generation followed by sequential diffusion-based geometry generation for vertices, edges, and faces.

### 7. GraphBrep: Learning B-Rep in Graph Structure for Efficient CAD Generation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2507.04765v1
- **Contribution:** Presents a graph diffusion model that explicitly learns compact surface topology as an undirected weighted graph, conditioned on surface features, for efficient B-Rep generation.
- **Why It Matters:** Direct B-Rep generation by modeling the joint distribution of geometry and topology using a graph representation and diffusion model, reducing computational redundancy.
- **Evidence:** Abstract states the method constructs a graph to represent surface topology and uses a graph diffusion model to learn topology conditioned on surface features.

### 8. HoLa: B-Rep Generation using a Holistic Latent Representation (2025)

- **Source:** `arXiv`
- **Link:** http://arxiv.org/abs/2504.14257v3

- **Evidence:** Abstract describes eliminating curves and vertices from the latent space by deriving them from surface pairs, creating a holistic representation for diffusion-based generation.
